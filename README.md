# Влажный архив — Гусь

Личная страница: большая жидкая надпись «Гусь», строка о себе, витрина с
кликабельными аватарками из пяти соцсетей и ссылки. Ледяная бумага, снег,
стекло, пиксельные подписи и бесконечный трек 1300p — «1 April 2024 / G Minor».
Сверху — огромная полупрозрачная надпись «Влажный архив»; стекло арки
просвечивает, поэтому она читается и за иконой.

Сборки нет: статические файлы, открываются двойным щелчком по `index.html`.
Интернет нужен только для шрифтов (Alegreya, IBM Plex Mono, Handjet, Oswald);
без сети сайт работает на системных шрифтах.

```
index.html   — разметка, тексты, ссылки, витрина
styles.css   — палитра, стекло, снег, сетка, анимации
app.js       — волны, снег, витрина, отражения, счётчик
side-left.js  — полный текст левой колонки
side-right.js — полный текст правой колонки
audio/       — 6 треков, случайный порядок
avatars/     — аватарки соцсетей
```

## Витрина с аватарками

В арке каждые 3,8 секунды сменяются пять аватарок. Активная — с прозрачностью
70% (`opacity: 0.7` у `.face.is-active`), поверх волн. Под аркой — подпись
«также известен как: …» с ником из той сети, откуда аватарка.

**Аватарки кликабельны:** нажми на видимую — откроется та же соцсеть, что и в
строке. У неактивных лиц клики и Tab отключены.

Аватарки подтянуты из профилей:

```
avatars/steam.jpg              — Steam (Гусь)
avatars/discord.png            — Discord (goose_kra)
avatars/tiktok.jpg             — TikTok (@goose_krak)
avatars/telegram-personal.jpg  — Telegram (@Mister_Pou)
avatars/telegram.jpg           — канал (@goose_cave), подпись «Видели в:»
```

Чтобы заменить — положите свой файл с тем же именем. Подпись берётся из
`data-nick`, а надпись в иконке — из `.face__net`:

```html
<div class="face" data-nick="@goose_cave" data-net="Telegram-канал">
  <a class="face__link" href="https://t.me/goose_cave" …>
    …
    <span class="face__net">Видели в:</span>
  </a>
</div>
```

## Счётчик уникальных

Справа сверху — просто число, без подписи. Сейчас это заглушка: `localStorage`
запоминает браузер и считает его один раз, прибавляя к базе 1240. При
перезагрузке число не меняется. В `app.js`:

```js
const seen = localStorage.getItem("uniqueUser");
let n = Number(localStorage.getItem("uniqueCount")) || 0;
if (!seen) {
  n += 1;
  localStorage.setItem("uniqueUser", "1");
  localStorage.setItem("uniqueCount", String(n));
}
visitsEl.textContent = String(1240 + Math.max(1, n));
```

Настоящее число уникальных посетителей требует бэкенда. Когда подключите
счётчик на GitHub — замените этот блок на запрос к своему API, оставив только
`visitsEl.textContent = …`.

## Время в Киеве

Между страной и статусом — живые часы: `01:35 · Киев`. Время всегда берётся из
`Intl` с зоной `Europe/Kiev` (пояс устройства не важен), обновляется раз в
секунду и не зависит от `?time=` / `?theme=` — те параметры меняют только
оформление. Разметка:

```html
<dd class="facts__clock"><time id="kyivTime">01:35</time> <span class="facts__zone">Киев</span></dd>
```

`updateKyivTime()` в `app.js` при каждом новом значении обновляет и `datetime`
(`2026-11-22T01:35`). Шрифт — Handjet, цифры табличные, поэтому ширина строки не
дёргается при смене минуты.

## Звук

В `audio/` шесть треков; при каждом заходе плейлист перемешивается и стартует
случайный:

- 1300p — «1 April 2024 / G Minor»;
- mittnetworkmusic — «27 March 2024 / B Minor»;
- mittnetworkmusic — «7 March 2024 / F Minor»;
- mittnetworkmusic — «24 April 2024 / Key Unknown»;
- Huerta — «All Wild Things Are Shy»;
- Anthony Naples — «365».

В разметке нет панели и кнопки play — только скрытый `<audio id="track">`;
`app.js` выбирает трек, играет его до конца и берёт следующий из перемешанной
очереди, без повтора подряд. Громкость — `audio.volume = 0.4`.

Если трек не загрузился или застрял, `app.js` сам берёт следующий. Браузеры не разрешают звук до первого действия. Поэтому трек стартует сразу
**без звука** (autoplay muted), а громкость включается с первого клика, тапа,
скролла или клавиши. Обойти политику автозапуска нельзя — это её легальный
обход: музыка уже играет, просто ожидает жест, чтобы стать слышимой.

## Как это устроено

**Волны по всей странице.** На `.shell`, `.backdrop-name` и `.side__track` висит
очень слабый SVG-фильтр `#melt` (`feTurbulence` + `feDisplacementMap`):
`baseFrequency` 0.0032/0.0052 медленно дышит 42 секунды, смещение — 3px.
Страница не «кипит», а еле заметно плывёт, как под грибами. Фильтр создан в
SVG-дефах в `index.html`, применяется к контенту (шапка, герой, ссылки, подвал,
фоновая вывеска и боковые колонки), не трогая снег и канвасы. На ≤760px,
в `prefers-reduced-motion` и в тихом режиме (`body.is-calm`) отключается.

**Лайк / дизлайк.** Справа от статуса — два пальца (вверх/вниз); под каждым просто чёрное число нажатий, без фона и плашки. Счётчик — стоящие уникальные голоса: снимаешь — число уменьшается, переключаешь — переезжает; при перезагрузке стоит. Хранится на браузер (`localStorage`, `warm.respect.v1`); настоящие уникальные IP без бэкенда не посчитать — для общего числа нужен API.\n\n**Жидкое имя.** `.name__first` растянуто только в длину (`scaleX(2.85)`), высота
не меняется. Внутри работает SVG-фильтр `#liquidName` (`feTurbulence` +
`feDisplacementMap`): он плавно меняет `baseFrequency` и `scale`, поэтому буквы
текут, но не прыгают и не обрезаются (область фильтра 220%); `scale` ходит
8–14, вода заметнее. В тихом режиме фильтр отключается.

**Фоновая вывеска.** `.backdrop-name` — огромная надпись «Влажный архив» вверху,
голубым градиентом с прозрачностью и медленным дыханием по высоте. Ширина
сжата (`scaleX(0.86)`, 11vw), чтобы не залезать на боковые колонки. Стекло
арки полупрозрачное (`rgba` + `backdrop-filter`), поэтому надпись видна и за
иконой.

**Цветной фон.** `.aura` — мягкие пастельные волны (лаванда, мята, персик,
голубой), размытые и еле заметные. Часть линий фона и гребень воды подкрашены
теми же цветами.

**Отражения.** У слов на бумаге (кроме арки, подписи под ней, статуса и подвала)
под текстом висит отражение: копия `aria-hidden` со сдвигом **в сторону под
наклон**, прозрачностью, маской и колыханием. Уровни: `soft` — обычные подписи,
`key` — ник, описание, заголовок и названия ссылок, `strong` — имя «Гусь»
(почти не видно, `opacity: 0.06`).
Отражения строит `buildReflections()` в `app.js`, они не ловят клики и не
попадают в Tab.

**Знаком с великими.** Справа от имени — колонка `greats`: 16 имён с ролями,
без нумерации, в две колонки (11px имена, 9.5px роли), слегка перетасованных,
но с сохранением приоритета — первые три остаются в левой колонке наверху.
Сдвинута чуть выше (top 82px) и по центру (left 61%, text-align: center);
роли — не серые, а синеватые (`#496a8c`). На ≤1180 колонка встаёт под факты,
на телефоне тоже две колонки и центрирование.

**Боковые колонки.** `.side--left` и `.side--right` — две узкие фиксированные
колонки по краям. Внутри — **полный** текст из файлов, он лежит в
`side-left.js` / `side-right.js` и рендерится в главы, подзаголовки и абзацы:
плотная вёрстка, тело 9px, заголовки 10.5–11px, креативная пунктуация
(`§`, `//`, `✦`, `—`). Шрифт Oswald + IBM Plex Mono, отступы по 4px — текст
прижат к краям, а сама колонка уже (88px при 1440) — до контента остаётся
больше воздуха. Цвет `#e9f2ff` с `mix-blend-mode: difference`: на светлом
темнеет, на тёмном светлеет. Прозрачность 0.22, маска по краям, медленный
бесшовный подъём вверх (`side-fall`, 900 с). Телефон из благодарностей скрыт.
На ≤1320 колонки убираются. Это декор: `aria-hidden`, без кликов.

**Отступ у вывески.** `.layout` начинается ниже (`padding-top` 130–170px),
чтобы «Влажный архив» не перекрывался контентом и её было видно.

**Место под будущий контент.** `.future` — пустой блок высотой 260–520px
между ссылками и водой; позже туда можно вставить новый блок.

**Короткая линия.** `.facts` ограничен `max-width: 420px` — полоска под именем
и описанием не доходит до «Знаком с великими».

**Общее покачивание.** `body > .shell`, `.footer__inner` и `.footer__signal`
медленно покачиваются по вертикали (`site-sway`, 19 секунд) — едва заметная
«тошнота». Горизонтального сдвига нет. Сам подвал и линия воды не
трансформируются: иначе на кромке экрана на 1px проступает бумага, а в фазе
сдвига вниз `body` получает лишний пиксель прокрутки. `body` — не
скролл-контейнер (`overflow-x: clip`), место под колесо прокрутки держит
`overflow-y: scroll` у `html`, так что второго ползунка справа не появляется.
Аватарка в арке тоже чуть желейно дышит.

**Окно-арка.** Форма вырезана через `clip-path` — SVG `#archClip` и правило
`.plate__window`. Внутри — стекло, поле колебаний, витрина и блик.

**Фон и волны.** `drawAmbient()` — дрейфующие линии; `drawPlate()` — поле
колебаний и круги на воде; `drawWaterline()` — волны у подвала; `drawSnow()` —
до 220 снежинок; `.frost` — морозная дымка. У воды три слоя: цвета идут от
дальнего гребня к подвалу, подмешиваясь к воде темы, и последний слой точно
совпадает с верхом подвала — на стыке нет шва.

**Мобильная версия.** Сверху вниз: надпись, икона-арка, имя, описание, факты, «Знаком с великими» (две колонки),
ссылки. Всё центрировано; строки ссылок — с центрированными названиями.

**Движение.** `prefers-reduced-motion` отключает волны, снег, смену аватарок,
жидкий фильтр, покачивание, отражения и колыхание вывески.

## Тема по киевскому времени

Оформление подстраивается под текущее время в Киеве. Цвет воды (отражение)
становится главным цветом темы: бумага, аура, вывеска, стекло арки, линия воды,
подвал, подпись под аркой и акцент. Внутри периода цвет стабилен — текущий
период и есть самый продолжительный, соседние цвета только на границах.

| Период | Время (Киев) | Цвет воды |
|---|---|---|
| ночь | 22:00–05:00 | индиго `#6d7cff` |
| рассвет | 05:00–08:00 | розовый `#ff9fb3` |
| утро | 08:00–11:00 | мятный `#5fdcc4` |
| день | 11:00–17:00 | голубой `#6fb7ff` |
| вечер | 17:00–21:00 | янтарный `#ffb36b` |
| поздний | 21:00–22:00 | фиолетовый `#b58cff` |

Ночь — 7 часов, день — 6; остальные короче. Цвет текущего периода применяется
к большинству элементов, а не размазывается с соседними.

### Как тестить

- `index.html?theme-debug=1` — панель внизу слева: ползунок времени, пресеты
  (ночь/рассвет/утро/день/вечер/поздний), цвет-свотч, кнопка «авто · сейчас».
- `index.html?time=21:30` — принудительное киевское время.
- `index.html?theme=night` — принудительная тема.
- В `app.js` — объект `THEME_CONFIG`:
  `time: "21:30"` (время), `force: "night"` (тема), `debug: true` (панель).
  Пустые строки — авто по Киеву.

Панель видна только с `?theme-debug=1`; обычный сайт чистый. Без параметров
время берётся из `Intl` с зоной `Europe/Kiev`, тема обновляется каждые 30 секунд.

Цвета темы живут в CSS-переменных (`--theme-paper-*`, `--theme-water`,
`--theme-aura-*`, `--theme-glass-*`, `--theme-mark-*`, `--theme-footer-*`),
а canvas-волны (фон, арка, вода, линейка) читают тот же объект темы.
